# Brand fonts for letter PDFs

The official letters (Letter of Appointment, Sponsor Letter) are styled in the
Sand Planet brand faces. Drop these TrueType files here and they render
automatically (the templates already declare the `@font-face` rules against this
directory); until then the letters fall back to Helvetica/Arial cleanly.

- `BarlowCondensed-SemiBold.ttf`  (weight 600) — headings / wordmark
- `BarlowCondensed-Bold.ttf`      (weight 700) — headings / wordmark
- `Inter-var.ttf`                 (variable)    — body text
- `IBMPlexMono-Medium.ttf`        (weight 500) — ref / date mono
- `IBMPlexMono-SemiBold.ttf`      (weight 600) — ref / date mono

Same faces the Company Profile PDF will use.
