{% comment %} Typography for the client-facing progress reports (weekly site report, unit progress). Deliberately NOT in _styles.html: that one is shared by invoices, payslips, claims and the DPR, and reflowing those to improve a report would be a large blast radius on documents already in clients' hands (owner 2026-08-31, "fonts and sizes ... a bit rigid"). DejaVu Sans rather than Helvetica: it is actually installed on the server, so it renders as drawn instead of being substituted, and its wider counters and even colour hold up in a dense table where Helvetica closes in. One scale, used consistently — the rigidity came from everything sitting at the same size and weight with hard rules between. {% endcomment %}
